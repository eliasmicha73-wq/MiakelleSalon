# Database Setup Instructions

## Database Name
miakelle_salon

## How to Import

### Method 1: Using phpMyAdmin
1. Open phpMyAdmin (http://localhost/phpmyadmin)
2. Click on "SQL" tab
3. Copy and paste the entire content of `miakelle_salon.sql`
4. Click "Go" to execute

### Method 2: Using MySQL Command Line
```bash
mysql -u root -p < miakelle_salon.sql
